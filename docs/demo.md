## 手机：3～5 分钟，必须在支持 ARCore 的真机上

- 0:00～0:40：展示设备型号、应用和相机授权，说明 API 指向统一后端。
- 0:40～1:40：缓慢扫描真实水平面，展示平面可视化；点击放置并移动橙色方块。
- 1:40～2:40：输入标题/描述，切换优先级；操作输入框、下拉框、按钮时观察标记没有移动；提交并展示成功编号。
- 2:40～3:40：空标题校验、错误后端地址引起的提交失败，展示表单与标记保留；恢复地址继续操作。
- 留下成功问题的 ID，电脑视频核对同一问题。若需录制模拟阶段素材，画面和文件名明确写“模拟”，不填为真机视频完成。

## 电脑：3～5 分钟

- 0:00～0:40：展示 Go 启动命令、数据文件位置、health 响应。
- 0:40～1:40：刷新 React 找到手机刚提交的同一 ID，展示标题、优先级和坐标。
- 1:40～2:20：状态从 open 改为 in_progress，再改为 resolved；刷新确认。
- 2:20～3:10：停止并重启同一个 Go 服务（保持 DATA_FILE），刷新核对 ID 和 resolved 状态还在。
- 3:10～4:00：关闭 Go，展示网页失败提示；恢复 Go 后点击重试，页面恢复。
